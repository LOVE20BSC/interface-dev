## 二、本轮实际改动（结构）

1. `liquidity-page.tsx`：删掉顶部 `intro` 段；第三个 tab 文案「社区流动性查询」→「社区流动性」；加池面板传入「去撤出」回调。
2. `add-liquidity-panel.tsx`：
   - 智能模式开关滑块定位修复（`left-0.5` + `translate-x`，与 `asset-protection-switch` 统一；行程按盒模型算 `44−2(border)−4(gap)−20(滑块)=18px`，`22px` 会压到胶囊右沿）；
   - 顶部补 `底池总LP / 我的LP（占比）/ 撤出` 抬头；
   - 两个输入行改为旧库结构：`输入 + 代币徽标`，下一行 `25% / 50% / 最高` + 右侧余额；
   - 补「当前池价格」行与方向切换；Hub 发生 swap 时补「添加后价格 + 涨跌幅」；
   - 删掉重复的空池说明（`firstMintHint`）与报价占位提示（`quoteEmptyHint`）；
   - 交易设置移到报价之后（旧库：「输入 → 报价/价格 → 滑点 → 按钮」）。
3. `my-liquidity-panel.tsx`：撤出输入行改为 `输入 + 流动性凭证徽标`，快捷按钮补齐「最高」文案；删掉「按比例快速填入」提示；卡内滑点预设与加池设置同档（0.1 / 0.5 / 1.0 / 2.5）；LP/占比与「持有」保持。
4. `liquidity-settings.tsx`：滑点预设补 `2.5%`（旧库有）；点预设即关闭弹层。
5. `copy-pages.ts`：`liquidity.*` 段新增/改写抬头、价格、快捷按钮文案；删掉上表列出的重复说明键。
6. 文档/测试：`m0-ux-spec.md` §3.13、`three-line/liquidity.md` §3（结构口径）、`e2e/liquidity-numbers.spec.ts`（快捷按钮/价格行断言）、16 张 `liquidity-*.png`。
