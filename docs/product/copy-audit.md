## 3 需要 owner 拍板（6 条）

只列真正有权衡的：每条都能省钱，但删掉的可能是「你以为用户需要、其实用户不看」或「spec 逐字要求」的二选一。

### 3.1 首页：同一屏两个同目标入口（F12 + F13）
- **现状**：余额行右侧「兑换」与入口行「兑换代币」同屏；有资格时资格卡主按钮「空投铸造」与入口行「空投铸造」上下相邻、同目标。
- **建议**：删余额行的「兑换」；资格卡出现时入口行不渲染「空投铸造」。
- **为什么需要你定**：spec §3.1 第 3 块要求「余额右侧『兑换』文字链」，第 4 块要求「三个常驻导航入口」。删任何一处都要动 spec；「常驻」是资格卡不出现时的兜底，动了要确认快照读失败时入口行仍完整。

### 3.2 我的 NFT：「当前身份」被标记四次（F14 + F15）
- **现状**：摘要「当前：{name}」、行内 pill「当前」、禁用按钮「当前身份」、整行着色；空态还多一条「持有 0 个身份」+「当前：未选择」与「你还没有身份。」重复。
- **建议**：保留 pill + 着色；删禁用按钮与摘要里的「当前：…」；空态不渲染摘要条。
- **为什么需要你定**：摘要条的存在理由是「不用扫列表也知道用的是哪个」，但当前行本来就置顶第一。真要留，就只留计数「持有 N 个身份」，不要名字。

### 3.3 空投「规则」里的「为什么金额会变」（F23）
- **现状**：金额卡小字「别人铸造后金额会变」+ 规则折叠里整段「为什么会变……铸造时以链上为准」。
- **建议**：删折叠那一条，规则只留「首币 / 快照 / 合约地址」。
- **为什么需要你定**：§3.4 把「为什么金额会变」写进了规则折叠的必含项；删它要改 spec。反过来说，金额正下方那句已经在回答同一个问题，折叠里再写一遍正是你说的「同样的意思反复说」。

### 3.4 铸造 dev/test：「名称必须以 Test 开头」两遍（F19）
- **现状**：输入框下静态规则行 + 不合规时检查行逐字重复同一句（还多一个 ✗）。
- **建议**：静态行保留；检查行改「✗ 还没加 Test 前缀」。
- **为什么需要你定**：也可以反过来删静态行、只留报错——但那样用户输入前不知道规则，会先撞一次错。两个方向都合理，取哪个请你定。

### 3.5 网络不对：页内卡片与页头药丸重复（F32）
- **现状**：页头红色药丸「网络不对，点此切换」+ 页内卡片标题「当前钱包连接的网络不对。」+ 同样的按钮，一屏两个同名按钮。
- **建议**：页内只留一句说明 + 「回首页」，切换动作交给常驻页头药丸。
- **为什么需要你定**：§3 通用写的是「链不对由外壳拦截」，但三张任务页现在各自造了一份卡；删页内按钮会让「页面里没有下一步按钮」——需要你确认这算不算死路（§0.7）。

### 3.6 兑换：报价「更新于 X 秒前」+「Xs 后更新」（F26）
- **现状**：信息块底部同一行左右各写一遍同一个时钟。
- **建议**：只留「更新于 X 秒前」，到期仍显示「报价已过期」并禁用主按钮。
- **为什么需要你定**：§3.5 明确要求「显示『更新于』与剩余倒计时」；倒计时是「马上会自动刷新」的唯一提示，删它要你认可「刷新是后台行为，不必告知」。
