- 联动规则（与旧库 `DEX/Liquidity.tsx` 的 zap 思路一致，但按 owner 的两句话重写）：

| | 智能模式开（默认，走 Hub） | 智能模式关（走 Router） |
| --- | --- | --- |
| 可填侧 | 两侧都可填，只填一侧也行 | 改哪一侧都可以；改完另一侧自动填好并**只读** |
| 另一侧谁算 | Hub `quoteLpWithNative` 自动配平（不够的一侧先兑换补齐） | 本地 `mirrorAmount(amountIn, reserveIn, reserveOut) = amountIn·reserveOut/reserveIn`（向下取整），纯展示/联动，不写链 |
| 切换输入侧 | 不需要（两侧都能填） | 点一下只读的那一侧，就改成由它驱动另一侧（否则第一下点在哪一侧，另一侧永远只能看） |
| 空池 / 首次建池 | Hub 不可用 → 自动降级 Router，两侧都必须填，写明原因 | 没有比例可依 → 两侧都必须填，`第一次建池：1 ETH = 10,000 TestX` 收在详情 |
| 授权对象 | Hub | Router |
| 写入 | `addLiquidityWithNative` / `addLiquidityWithToken`（两侧数量都传） | `addLiquidityETH`（`planDualAdd` 按比例截断） |

- 联动常量与单测：`lib/liquidity-math.ts` 新增 `mirrorAmount`，`liquidity-math.test.ts` 覆盖 `1000 TestLOVE20 ↔ 0.5 ETH`、向下取整与空储备返回 0。
