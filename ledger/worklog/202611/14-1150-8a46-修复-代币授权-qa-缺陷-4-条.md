### D1 默认代币错（P2）· 已修
根因：`approval-panel.tsx` 原 fallback effect 只要 `catalog.communityTokens[0]` 为空就先取 `wrappedToken` 并写入 `selectedToken`；社区代币目录（Launch `tokens` 分页 + 元数据）晚一拍到达后，effect 因 `selectedToken !== undefined` 直接 return，默认值就永久停在 TestWETH（余额 0）。
修法：抽纯函数 `pickDefaultApprovalToken`（`src/features/approve-token/lib/approval-tokens.ts:29`）——社区目录 `communityLoading` 期间返回 `undefined`（不决定默认），settled 后才按「社区代币 → 包装原生币 → LP」取第一个；页面 `approval-panel.tsx:163` 只在拿到结果时写一次选择。
验证：单测 `approval-tokens.test.ts`（加载中不选回退 / 加载完成选社区代币 / 回退顺序）4 条通过；e2e 断言已加（D1 用例：首次进入 + F5 刷新都不手动选代币，断言 token=TestLOVE20、余额 `TestLOVE20 余额 99,799,100`）。**e2e 待跑，见下「环境阻塞」**。

### D2 取消签名无可见反馈（P2）· 已修
根因：发送失败只写进页面底部 `role=alert` 错误条，而确认 sheet 仍在打开，错误条被遮罩挡住（QA 几何校验 y ≥ 弹层 y）。
修法：`ApprovalConfirmSheet` 增加可选 `error` 属性，在确认/取消按钮上方渲染 `approvals-confirm-error`（`role=alert`）：失败结论 + 可执行提示「这次没有产生交易。可以再点一次上面的按钮重试，或点「取消」先关掉这个窗口。」（copy `approvals.confirmErrorHint`）。弹层保持打开、按钮恢复可点、额度不变；`approval-panel.tsx:811` 把 `tx.error` 同时传给弹层，关闭弹层后页面底部错误条仍在。

### D3 RPC 不可用被误报成「没有代币」（P2）· 已修
根因（两层）：① wagmi `useReadContracts` 在传输层失败时不会让 query 进 error，而是把每个调用解析成 `{status:'failure'}` 的**成功** `data`；`useSwapCatalog.isError` 只看 `pages.isError`/`metadata.isError`/`metadata.data` 失败项，漏了 `pages.data` → 代币目录既不 loading 也不 error。② 面板把 `token === undefined` 一律画成「还没有可以查看的代币」，余额行又因为 `token === undefined` 永远「读取余额中…」。
修法：`use-swap-catalog.ts:182-193` 的 `isError` 同时检查 `pages.data` 的 failure 项；`useTransferCatalog` 暴露 `communityLoading / communityError / refetch`（`use-transfer-catalog.ts:51,228`）；面板 `approval-panel.tsx:664-680` 在目录失败时渲染 `approvals-block-network-error`「暂时读不到网络数据」+「…这不是没有代币，请检查网络后重新读取。」+「重新读取」，余额行写「余额暂时读不到」；`retryCatalog` 同时重拉目录、余额、额度；目录 loading 时显示「正在读取代币列表…」而不是空态。
验证（**真实浏览器，本轮已完成**）：dev server（5199，`VITE_ANVIL_RPC=http://127.0.0.1:8591` 无监听=链不可用）+ 注入钱包，390×844 浅色与 1280×800 深色都出现网络错误态、「重新读取」可点、页面不含「还没有可以查看的代币」/「请添加一个 ERC20 地址」、无 pageerror；证据 `/tmp/approvals-dsh-verify/approvals-d3-network-error-light-mobile.png`、`/tmp/approvals-dsh-verify/approvals-d3-network-error-dark-desktop.png`。e2e 断言已加（route abort 全部 RPC → 网络态 → unroute → 点「重新读取」自愈，不需要刷新页面）。**e2e 待跑**。

### D4 内置 TestWETH 被加成自定义代币（P3）· 已修
